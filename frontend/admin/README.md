# Restored Church - Admin Portal

The Admin Portal is a specialized dashboard designed for church administrators to manage resources, oversee financial data, and monitor platform health.

## Core Features

- **Finance Dashboard**: Real-time tracking of weekly contributions, special missions, and benevolence income.
- **Expense Management**: Visual breakdown of operational costs and central administration budgets.
- **Data Visualization**: Interactive charts powered by Chart.js for intuitive financial oversight.
- **Firebase Integration**: Seamless connection to Firestore for persistent data management.

## Technology Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + [daisyUI](https://daisyui.com/)
- **Database**: [Firebase Firestore](https://firebase.google.com/docs/firestore)
- **Charts**: [Chart.js](https://www.chartjs.org/) via `react-chartjs-2`
- **Testing**: Vitest + React Testing Library

## Getting Started

1.  **Install Dependencies**:

    ```bash
    pnpm install
    ```

2.  **Development Server**:

    ```bash
    pnpm dev
    ```

3.  **Run Tests**:
    ```bash
    pnpm test
    ```

The application will be available at `http://localhost:5173`.
