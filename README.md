# Restored Church Platform

A multi-church platform for administration and tools.

## Overview

This is a repository for a multi-church platform that provides tools and resources for church administration. The platform is designed to be scalable, secure, and easy to use.

## Technology Stack

- Frontend: React
- Backend: Node.js with Express.js

## Getting Started

1. Clone the repository
2. Run `pnpm install` to install dependencies
3. Run `pnpm run dev` to start the development server
4. Open `http://localhost:3000` in your web browser to view the application
